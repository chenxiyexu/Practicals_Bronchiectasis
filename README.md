# Practicals_Bronchiectasis
Practicals in IRYCIS for UAM´s Master in Bioinformatics and Computational Biology

The scripts require the conda environment detailed in Libraries_env.yml. Using conda env create -f Libraries_env.yml will recreate the adequate environment with everything required to run the scripts- 

Usage is permitted with proper credits! Hopefully this code can be of help to someone. 


There is also a folder named Complementary_images, all the images inside can be obtained through running the code but as some steps are quite RAM-heavy and depending on the volume of daata some computers cannot handle it, for reviewing purposes they are available.
