# Practices_Bronchiectasis
Code used during Chen Xi Ye Xu´s practicals at IRYCIS for studying the lung microbiome in patients with bronchiectasis. 

Instructions for use:
To recreate the conda environment used to run the code you can use "conda env create -f Libraries_env.yml" from a Linux terminal window. 

Credits appear on the scripts that were updates/created on top of existing code. If no credits are given it is because the code was written entirely from scratch. To fix some bugs and to create the final text summaries for the logs, basic generative AI was used (ChatGTP). None of the important basis of the code or written reports associated with this project were made with AI. 

Free usage of this code is permitted as long as it is properly credited to both the original creators of the code and to Chen Xi Ye Xu.
